ХЭРХЭН АЖИЛЛУУЛАХ ВЭ?
─────────────────────

1. Энэ хавтасыг (lp-suite-v2) хаашаа ч хуулна (Desktop, Documents г.м)
2. Хавтсаа задлаагүй бол задлана (.zip)
3. Хавтсыг нээж "index.html" файлыг ДАВХАР ДАРНА

   ВУАЛЯ — браузер таны default browser-аар нээгдэж аппликейшн ажиллана.

ХЭРЭВ АЛДАА ГАРВАЛ:
───────────────────

Хэрэв "Empty page" эсвэл алдаа гарвал, хүчтэй refresh хийгээрэй
(Ctrl+Shift+R эсвэл Cmd+Shift+R Mac дээр).

Бас интернет холболт шаардлагатай (CDN-ээс KaTeX, PDF татагдана).
Дараа нь cache-д хадгалагдсаны дараа интернет хэрэггүй болно.
