Бүлэг 4.3
4.3.1–4.3.3 · Тодорхойлогч бодох

2×2 ба 3×3-ын тодорхойлогч

Тодорхойлолт

Тодорхойлогч (Determinant) — зөвхөн квадрат матрицад тодорхойлогддог, тухайн матрицыг нэг скаляр тоонд буулган илэрхийлэх үзүүлэлт. Тэмдэглэгээ: det(A), |A|, эсвэл Δ.

2×2: det(A) = a₁₁a₂₂ − a₁₂a₂₁ = ad − bc
“Модон урлал”: Δ = (4 × 4) − (2 × 2) = 16 − 4 = 12
Гол диагоналийн элементүүдийн үржвэрээс туслах диагоналийн элементүүдийн үржвэрийг хасна.
Саррюсын дүрэм (Sarrus' Rule) — зөвхөн 3×3
Матрицын эхний хоёр баганыг баруун талд дахин бичээд, зүүнээс баруун тийш чиглэсэн гурван диагоналийн үржвэрийг нэмж, баруунаас зүүн тийш чиглэсэн гурвыг хасна.
det(A) = aei + bfg + cdh − ceg − bdi − afh
Алгебрын гүйцээлтээр задлах (Cofactor Expansion)
Илүү ерөнхий — дурын хэмжээтэй квадрат матрицад ажиллана. Эхний мөрөөр задалбал:
det(A) = a · C(1,1) + b · C(1,2) + c · C(1,3)
C(i,j) — тухайн мөр, баганыг арилгасны дараах 2×2 дэд матрицын тодорхойлогч (минор) дээр (−1)i+j тэмдгийг үржүүлсэн утга.

4.3.4 · Тодорхойлогчийн эдийн засгийн утга

Δ-ийн тэмдэг юу хэлж байна вэ?

Δ > 0 · эрүүл систем

Тогтвортой, төрөлжсөн үйлдвэрлэл

Гол диагоналийн үржвэр туслах диагоналийнхаас их — бүтээгдэхүүн бүр өөрийн үндсэн нөөцөөсөө хамгийн их хамааралтай. Ширээнд мод (4), сандалд цаг (4) түлхүү ордог.

Менежерт: мод нэмбэл шийд “ширээгээ нэм” гэж хэвийн логикоор зөвлөнө. Бизнесээ итгэлтэй тэлж болно.

Δ < 0 · парадокс

Hawkins–Simon нөхцөл алдагдав

Туслах диагональ гол диагоналиасаа давсан — бүтээгдэхүүнүүдийн хөндлөн нөлөө, нэгнийх нь нөөцийг нөгөө нь булаах шинж хэтэрсэн.

Парадокс: 10 м.куб мод нэмж авахад ширээний үйлдвэрлэлийг нэмэх биш, харин хасаж, оронд нь сандлыг хүчээр нэмэх шаардлагатай болно.

Δ = 0 · үгүйсгэгдсэн

Шугаман хамааралтай систем

Мөрүүд (эсвэл багана) хоорондоо шугаман хамааралтай — нэг хязгаарлалт нөгөөгийнхөө тогтмол үржвэр.

A⁻¹ оршин байхын цорын ганц нөхцөл нь det(A) ≠ 0. Систем огт шийдгүй (Infeasible), эсвэл хязгааргүй олон шийдтэй. Матрицын аргаар цаашид бодох боломжгүй.

Санамж: Δ < 0 үед “танай бүтээгдэхүүнүүдийн орцын норм хэтэрхий ижилхэн, нөөцөө үр ашиггүй булаацалдаж байна — технологийн жороо дахин хянаж өөрчил!” гэсэн анхааруулга ирж байна гэж ойлго.

Урвуу матриц (Inverse Matrix)

Матрицад хуваах үйлдэл байдаггүй тул AX = B системийг шууд “хувааж” болохгүй — X-ийг зөвхөн урвуу матрицын тусламжтайгаар гаргаж авдаг.

Бүлэг 4.4
4.4.1–4.4.2 · X-ийг хэрхэн гаргах вэ?

AX = B-ээс X = A⁻¹B хүртэл

AX = B
A⁻¹ · AX = A⁻¹ · B  (зүүнээс A⁻¹-ээр үржүүлэв)
I · X = A⁻¹ · B  (A⁻¹A = I учраас)
X = A⁻¹ · B  (I · X = X учраас)
A · A⁻¹ = A⁻¹ · A = I  ·  Урвуу матриц зөвхөн det(A) ≠ 0 үед л оршин байна
Санамж — хамгийн түгээмэл алдаа

Матрицын үржвэрт байр солих чанар байхгүй тул (AB ≠ BA), A⁻¹-ээр тэгшитгэлийн хоёр талыг хоёуланг нь адилхан зүүнээс үржүүлэх ёстой. Хэрэв санамсаргүйгээр баруунаас үржүүлбэл (жишээ нь AX · A⁻¹) тэгшитгэл алдагдана.

4.8 · Матрицын аргын хязгаарлалт

Хэзээ ажиллах, хэзээ ажиллахгүй вэ?

✓Тэгшитгэл хэлбэр — хязгаарлалтууд бүгд (=) хэлбэртэй, эсвэл оновчтой цэг дээр тэгшитгэл болгож болохуйц байх

✗≤ эсвэл ≥ хэлбэртэй бөгөөд аль хязгаарлалт хүчинтэй (binding) болохыг урьдчилан мэдэхгүй үед
✗det(A) = 0 — хязгаарлалтууд хоорондоо шугаман хамааралтай үед
Тэгвэл практикт юу ашиглах вэ?

Бодит бизнесийн бодлого ихэвчлэн олон, ялгаатай хязгаарлалттай тул матрицын арга нь голчлон онолын ойлголт өгөх, суурь тавих зорилготой. Практикт: симплекс арга → Бүлэг 5 (≤ хязгаарлалттай ерөнхий бодлогод), Big-M арга → Бүлэг 6 (≥ болон = хязгаарлалттай бодлогод).

1Матрицын үржвэрийн гурван шинж: байр солих чанар байхгүй (AB ≠ BA), бүлэглэх чанар ((AB)C = A(BC)), задлах чанар (A(B+C) = AB + AC).
2Хязгаарлалтын системийг AX = B хэлбэрт оруулаад X-ийг X = A⁻¹B томьёогоор гаргана — матрицад хуваах үйлдэл байдаггүй тул зөвхөн зүүнээс A⁻¹-ээр үржүүлнэ.
3Тодорхойлогчийн тэмдэг системийн “эрүүл мэнд”-ийг хэлнэ: Δ > 0 эрүүл, Δ < 0 Hawkins–Simon парадокс, Δ = 0 урвуу матриц огт байхгүй.
4A⁻¹-ийн элемент бүр “1 нэгж нөөц нэмэгдвэл бүтээгдэхүүн хэдээр өөрчлөгдөх вэ?” гэсэн эдийн засгийн утгатай — сүүдрийн үнэтэй шууд холбоотой.
