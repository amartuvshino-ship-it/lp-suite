9.1

Бүхэл тоон программчлалын танилцуулга

«0.7 машин», «3.4 ажилтан», «2.5 онгоц» — практик утгагүй хариу. Яг энэ асуудлыг шийдэхийн тулд зохиогдсон нь бүхэл тоон программчлал.

Бүлэг 9.1
9.1.1 · Бүхэл тоон программчлал гэж юу вэ?

Ганцхан мөр нэмэгдэхэд бүх зүйл өөрчлөгдөнө

Z = c₁x₁ + c₂x₂ + … + cₙxₙ  → max (эсвэл min)
хязгаарлалтууд:
a₁₁x₁ + a₁₂x₂ + … + a₁ₙxₙ ≤ b₁   …
x₁, x₂, …, xₙ ≥ 0
xᵢ ∈ Z   ← ганцхан энэ мөр нэмэгдэнэ
xᵢ ∈ Z (бүхэл тоонуудын олонлог)  ·  эсвэл xᵢ ∈ {0, 1, 2, 3, …}

Бүтцийн хувьд энгийн ШП-ийн бодлоготой яг адилхан: зорилгын функц, хязгаарлалтын систем, үл сөрөг байх нөхцөл бүгд хэвээрээ. Гэвч энэ нэг мөр нь бодолтын бүх арга барилыг өөрчилдөг.

Бүлэг 9.1.1
9.1.2–9.1.3 · Хэзээ ашиглах ба яагаад чухал вэ?

Хэзээ бүхэл тоон нөхцөл зайлшгүй вэ?

1

Хуваагдахгүй объект

Хүн, машин, онгоц, үйлдвэр, барилга — бодит биет зүйлс.

2

«Тийм / үгүй» шийдвэр

Төсөл сонгох эсэх, байршил сонгох эсэх, гэрээ байгуулах эсэх.

3

Тоолж болох нэгж

Малын толгойн тоо, ажилтны тоо, захиалгын тоо.

Санах дүрэм

Асуултынхаа хариуг «хэдэн …» гэж тоолж чадаж байвал («хэдэн ажилтан», «хэдэн машин», «хэдэн толгой мал») — тэр нь ихэвчлэн бүхэл тоон программчлалын бодлого.

✗Яагаад тоймлож (round) болохгүй вэ? (а) Тоймлосон хариу оновчтой шийд байхаа болих магадлалтай
✗(б) Тоймлосон хариу нөөцийн хязгаараас давж, огт боломжгүй (infeasible) шийд болж болзошгүй

9.1.4 · Симплекс аргатай уялдаа

Бүхэл тоон программчлал = симплекс + нэг нөхцөл

Бүхэл тоон программчлал  =  симплекс арга  +  «бүхэл тоо байх ёстой» нөхцөл
Бүлэг 5-т сурсан симплекс арга нь бүхэл тоон программчлалын суурь болдог
Бүхэл тоон нөхцөлийг чөлөөлөх (LP Relaxation)

Эхлээд бүхэл тоон нөхцөлийг түр тавьж орхино: x ≥ 0 гэдгийг л баримталж, x ∈ Z гэдгийг түр орхиод энгийн ШП-ийн бодлого мэт симплекс аргаар бодно. Дараа нь хариу бүхэл тоо мөн эсэхийг шалгаж, бутархай гарвал Хэсэг 9.3, 9.4-ийн тусгай аргуудаар цэгцлэн бүхэл тоон оновчтой шийд рүү шилжинэ.

↔ Бүлэг 2-ын «Модон урлал» ХХК-д x₁ = 20, x₂ = 10 гэсэн бүхэл хариу гарсан нь зөвхөн тохиолдлын таарамж байсан. Ерөнхийдөө симплекс арга x₁ = 2.5, x₂ = 3.7 мэтийн бутархай хариу гаргадаг.

Салбарлан зааглах арга

Branch and Bound — бүхэл тоон программчлалын хамгийн чухал, хамгийн өргөн хэрэглэгддэг арга. Excel Solver, LINGO, CPLEX, Gurobi зэрэг арилжааны программ хангамжийн цөмд яг энэ алгоритм ажилладаг.

Бүлэг 9.3
9.3.1–9.3.2 · Үндсэн санаа ба модны бүтэц

Нэг том бодлогыг хоёр жижиг болгон задлах

  • 1Бүхэл тоон нөхцөлийг чөлөөлж (LP Relaxation), симплекс аргаар бодно
  • 2Хариу аль хэдийн бүхэл тоо бол — оновчтой шийд тэр дороо олдсон
  • 3Бутархай хариу гарвал тэр хувьсагчаар салаалуулж, хоёр дэд бодлого болгон хуваана
  • 4Бүхэл тоон оновчтой шийд олдох хүртэл давтана

Хязгаар

Зангилааны Z утгын дээд (эсвэл доод) хязгаар — тэр салаагаар цааш шалгах эсэхийг тодорхойлно.

Бүлэг 9.3.1–9.3.2
9.3.3 · Хязгаарлах (Bounding) дүрэм

Хэзээ зангилааг дуусгавар болгох вэ? (max бодлого)

✓(1) Бүхэл тоон шийд. Зангилааны чөлөөлсөн бодлогын шийд аль хэдийн бүхэл тоо бол — нэр дэвшигч (incumbent) шийд болно. Одоогийн хамгийн сайнтай харьцуулж, илүү бол шинэчилнэ.
✂(2) Доогуур Z утга. Зангилааны LP дээд хязгаар Z нь одоогийн хамгийн сайн бүхэл тоон шийдийн Z-ээс бага бол — энэ салаагаар явсан ч илүү сайн хариу гарахгүй тул тайрч хаяна (pruning).
✗(3) Шийдгүй (infeasible). Зангилааны чөлөөлсөн бодлого боломжит шийдгүй бол тэр зангилаа «үхсэн» — цаашид салаалуулах шаардлагагүй.
↔ Бүлэг 7-той холбоо

Энэ дүрмийн онолын үндэс нь хосмог онол болон сүүдрийн үнийн логиктой шууд холбоотой: чөлөөлсөн бодлогын Z утга нь тухайн салааны хамгийн өөдрөг (боломжит дээд) үнэлгээ болдог.

Бүлэг 9.3.3
9.3.4 · Алгоритмын алхмууд

Зургаан алхам

  • 1Бүхэл тоон нөхцөлийг чөлөөлсөн анхны бодлогыг симплекс аргаар бод (Бүлэг 5)
  • 2Хариу бүхэл тоо эсэхийг шалга. Бүгд бүхэл бол → оновчтой шийд. Бутархай xⱼ байвал → салаалуулна
  • 3Бутархай xⱼ = a байвал: Салаа 1: xⱼ ≤ ⌊a⌋  ба  Салаа 2: xⱼ ≥ ⌈a⌉  (жишээ нь a = 3.7 → x ≤ 3 ба x ≥ 4)
  • 4Салаа бүрийн шинэ чөлөөлсөн бодлогыг симплекс аргаар бод
  • 59.3.3-ын хязгаарлах дүрмээр аль зангилааг тайрч, аль зангилааг үргэлжлүүлэхээ шийд
  • 6Бүх зангилаа дуусгавар болтол (fathomed) 3–5-р алхмыг давт. Үлдсэн хамгийн сайн бүхэл тоон шийд нь оновчтой шийд мөн

Гол зарчим — номын туршид давтагдана

Чөлөөлсөн бодлогын Z = 21 байсан бол бүхэл тоон жинхэнэ оновчтой Z = 20 болж буурчээ. Энэ нь санамсаргүй зүйл биш: бүхэл тоон нөхцөл нэмэгдэх тусам боломжит муж нарийсдаг тул бүхэл тоон оновчтой шийд нь чөлөөлсөн бодлогын шийдтэй тэнцүү, эсвэл түүнээс дор байна (max бодлогын хувьд) — хэзээ ч илүү сайжирдаггүй.

Мод дээрх бүх зангилаа дуусгавар болсон (бүгд бүхэл тоон шийд гарсан) тул хайлт дуусна. ★ Оновчтой шийд: x₁ = 4, x₂ = 0, Z = 20.

Бүлэг 9.3.5
Интерактив · Түргэн тест

Ойлгосон эсэхээ шалгая

Гурван асуулт — гурвуулаа салбарлан зааглах аргын гол дүрмүүд дээр. Зөв хариултыг товшвол тайлбар нээгдэнэ.

1. Чөлөөлсөн бодлогын шийд ZLP = 34.5 гарлаа. Энэ бол max бодлого, зорилгын коэффициент бүхэл. Бүхэл тоон оновчтой Z ямар байх вэ?
Z_IP ≤ Z_LP (9.3.5-ын зарчим), мөн Z бүхэл тоо тул Z ≤ ⌊34.5⌋ = 34. Яг 34 гэж батлах аргагүй — түүнээс бага ч байж болно.
2. Нэг зангилааны LP дээд хязгаар Z = 17.2. Одоогийн хамгийн сайн бүхэл тоон шийд Z = 19. Юу хийх вэ?
Хязгаарлах дүрэм (2): дээд хязгаар нь одоогийн хамгийн сайн шийдээс бага тул энэ салаагаар илүү сайн хариу гарах боломжгүй — тайрна.
3. Чөлөөлсөн шийдэд x₁ = 3.7 гарлаа. Ямар хоёр салаа үүсгэх вэ?
Салаа 1: x₁ ≤ ⌊3.7⌋ = 3  ·  Салаа 2: x₁ ≥ ⌈3.7⌉ = 4. Ингэснээр 3 < x₁ < 4 муж бүхэлдээ хасагдана.

Хамгийн алдартай, өргөн хэрэглэгддэг хувилбар. 1958 онд америкийн математикч Ральф Гомори нээсэн. Чухал давуу тал нь симплекс хүснэгтээс шууд, механик байдлаар байгуулагддагт оршино — энэ нь компьютерийн алгоритм болгон хөрвүүлэхэд маш тохиромжтой.

9.5.1 · Үүргэвчийн бодлого (Knapsack Problem)

Хязгаарлагдмал багтаамжид хамгийн үнэ цэнэтэй багц

max Z = Σⱼ vⱼ·xⱼ  (нийт үнэ цэнэ)
Σⱼ wⱼ·xⱼ ≤ W  (хамгийн их багтаамж)
xⱼ ∈ {0, 1}  (сонгосон / сонгоогүй)
vⱼ — үнэ цэнэ  ·  wⱼ — жин  ·  W — үүргэвчийн багтаамж

Зургаан гол санаа

1Бүхэл тоон программчлал бол хувьсагч заавал бүхэл тоо байх ёстой ШП-ийн бодлого — бодит амьдрал дээр хамгийн өргөн хэрэглэгддэг хэсэг.

3Бүхэл тоон нөхцөлийг чөлөөлөх (LP Relaxation) — бүх бодолтын анхны алхам. Бутархай хариуг зүгээр дугуйлж болохгүй.
4Салбарлан зааглах арга — зангилаа, салаа, хязгаар; бутархай хувьсагч дээр хоёр салаа болгон хувааж, хязгаарлах дүрмээр тайрч (pruning) хайдаг гол цөм арга.
