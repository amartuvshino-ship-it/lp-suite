Хосмог бодлогын танилцуулга

Өмнөх зургаан бүлэг «Хязгаарлагдмал нөөцөөрөө хэрхэн хамгийн их ашиг олох вэ?» гэж асуусан. Одоо бид өөр асуулт тавина: «Тэрхүү нөөцийн жинхэнэ, далд үнэ цэн хэд вэ?»

Бүлэг 7.1
7.1.1 · Хосмог бодлого гэж юу вэ?

Бодлого бүрийн цаана толин тусгал нь байдаг

Аливаа нэг шугаман программчлалын бодлогын цаана, түүнтэй математикийн хувьд салшгүй холбоотой өөр нэг «толин тусгал» бодлого үргэлж оршин байдаг.

Хос нэр томьёо

Анхдагч бодлого (Primal Problem) — бодит амьдралаас шууд гарч ирсэн бодлого.
Хосмог бодлого (Dual Problem) — яг тэр мэдээллийг эсрэг талаас харсан бодлого.

Анхдагч талаас

«Хэдэн ширээ, хэдэн сандал хийвэл хамгийн их ашигтай вэ?»

«Тэрхүү үйлдвэрлэлд орсон мод, цаг өөрсдөө хэдэн төгрөгийн үнэ цэнтэй вэ?»

7.3.1–7.3.2 · Ерөнхий дүрэм ба хувиргах алхмууд

Бүх зүйл байраа солино

Анхдагч    max Z = cᵀx  ·  Ax ≤ b  ·  x ≥ 0
Хосмог    min W = bᵀy  ·  Aᵀy ≥ c  ·  y ≥ 0
c — зорилгын коэффициентийн вектор  ·  b — нөөцийн (RHS) вектор  ·  A — хязгаарлалтын матриц  ·  Aᵀ — A-гийн хөрвүүлэг
Алхам 1

max ↔ min шилжинэ

Анхдагч бодлого max бол Хосмог нь min болно (эсвэл эсрэгээр).

Алхам 2

Хувьсагч ↔ хязгаарлалт

Анхдагчийн n хувьсагч → Хосмогийн n хязгаарлалт. Анхдагчийн m хязгаарлалт → Хосмогийн m хувьсагч.

Алхам 3

Тэмдгийн эсрэг харилцаа

max бодлогод: Анхдагчийн ≤ хязгаарлалтад y ≥ 0, Анхдагчийн x ≥ 0 хувьсагчид ≥ хязгаарлалт харгалзана.

Алхам 4

Коэффициент байраа солино

c → Хосмогийн RHS, b → Хосмогийн зорилгын коэффициент, A → Aᵀ.

Бүлэг 7.4
7.4.1–7.4.2 · Хосмогийн үндсэн теорем

Z* = W*

«Хэрэв Анхдагч бодлого оновчтой шийдтэй бол Хосмог бодлого ч мөн оновчтой шийдтэй байх бөгөөд эдгээр оновчтой утга хоорондоо тэнцүү байна.»
Z* = W*
Z* — Анхдагч бодлогын оновчтой утга  ·  W* — Хосмог бодлогын оновчтой утга
Эдийн засгийн утга

Хамгийн их ашиг = Хамгийн бага нөөцийн үнэлгээ

Компанийн үйл ажиллагаанаас олох боломжтой хамгийн их ашиг нь түүний эзэмшдэг бүх нөөцийн зах зээлийн бодит үнэ цэнтэй яг тэнцүү байдаг — алдагдалгүй, зөрөөгүй тэгш төлбөр.

Практик ач холбогдол

Нэгийг мэдвэл нөгөө нь бэлэн

Бүлэг 7.4.1–7.4.2
7.4.3–7.4.4 · Сул ба хүчтэй хосмогийн теорем

Эхлээд тэнцэтгэл биш, дараа нь тэнцүү

Сул хосмогийн теорем (Weak Duality)

«Ямар нэг боломжит Анхдагч шийд (Z) ба ямар нэг боломжит Хосмог шийд (W) хоёрын хувьд: Z ≤ W (max бодлогод).»

Анхдагчийн ямар ч боломжит ашиг Хосмогийн ямар ч боломжит нөөцийн үнэлгээнээс хэзээ ч давахгүй. Зөвхөн хоёулаа оновчтой шийддээ хүрсэн үед л Z = W болно.

Aᵀy ≥ c  ⟹  cᵀx ≤ (Aᵀy)ᵀx = yᵀAx
Ax ≤ b  ⟹  yᵀAx ≤ yᵀb
⟹   cᵀx ≤ yᵀb   буюу   Z ≤ W
Сул хосмогийн теоремын товч нотолгоо
Хүчтэй хосмогийн теорем (Strong Duality)

«Хэрэв Анхдагч бодлого оновчтой шийдтэй бол Z* = W* яг тэнцүү.» Гэйл, Кун, Такер нар 1950-иад оны эхээр нотолсон — KKT нөхцөлийн тусгай тохиолдол.

7.4.5 · Бие биеэ нөхөх сул төлөвийн теорем

Бие биеэ нөхөх сул төлөв

Дүрэм 1 · Хязгаарлалт → хувьсагч

Нөөц илүүдэлтэй бол үнэ нь тэг

Хэрэв Анхдагчийн нэг хязгаарлалт сул (slack > 0, нөөц бүрэн ашиглагдаагүй) байвал тэрхүү нөөцийн Хосмог хувьсагч (сүүдрийн үнэ) тэг байна.

Дүрэм 2 · Хувьсагч → хязгаарлалт

Үйлдвэрлэж байгаа бол хязгаарлалт хатуу

Хэрэв Анхдагчийн хувьсагч эерэг (x₁ > 0, бүтээгдэхүүн үйлдвэрлэгдэж байгаа) бол түүнд харгалзах Хосмогийн хязгаарлалт яг тэнцүү (binding) байна.

Энгийн үгээр

«Нөөц дутагдалгүй, илүүдэлтэй бол тэр нөөцийн үнэ 0 байна — учир нь илүүдэлтэй зүйлийг нэмж авах хэрэггүй. Харин бүтээгдэхүүн бодитоор үйлдвэрлэгдэж байгаа бол түүнд орсон нөөцийн үнэ яг тэр бүтээгдэхүүний ашигтай тэнцэх ёстой.»

Хос бүрийг өөрөө шалга

Хос 1 · Хязгаарлалт ↔ y₁
Мод: 4x₁+2x₂ ≤ 100
Оновчтой цэгт 4(20)+2(10) = 100
s₁ = 0 тул хязгаарлалт хатуу → y₁ тэг байх албагүй. Бодит утга: y₁ = 10,000₮ (эерэг).
Хос 2 · Хязгаарлалт ↔ y₂
Цаг: 2x₁+4x₂ ≤ 80
Оновчтой цэгт 2(20)+4(10) = 80
s₂ = 0 тул хязгаарлалт хатуу → y₂ тэг байх албагүй. Бодит утга: y₂ = 5,000₮ (эерэг).
Хос 3 · x₁ ↔ хязгаарлалт
Ширээ: оновчтой шийдэд x₁ = 20. Ширээ үйлдвэрлэгдэж байна уу?
